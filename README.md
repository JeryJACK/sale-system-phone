# 九源祥销售 · 手机端

## 文件
- `index.html` 入口
- `mobile.css` 手机端样式
- `mobile.js` 页面与业务逻辑
- `config.js` 后端 API 地址
- `manifest.webmanifest` / `icon.svg` 手机桌面安装图标

## 部署
把本目录整体放到网页服务器的一个目录下，例如 `https://你的域名/mobile/`。
打开 `index.html`，在登录页填写 API 地址（生产为 `https://118.178.95.24/api`）并登录。
手机端与电脑网页版、EXE 共用同一套 FastAPI + MariaDB 后端，不另建数据库。

## 已实现
- 开单：客户搜索、商品搜索、多规格、任意包装单位、数量/单价、整件价自动换算、生产日期/保质期自动推算、退货标记、单据备注。
- 订单：按今天/近7天/本月/全部筛选，订单详情、修改、作废。
- 客户：搜索、新增、编辑，历史金额与单量。
- 商品：搜索、规格/单位/参考价，新增商品、编辑商品、包装单位换算、整件价自动换算最小单价，直接加入开单。
- 进货：新增进货、任意包装单位、生产日期自动推算保质期、进货单详情与作废。
- 首页/统计：今日与本月销售、客户数、商品数、客户排行、商品销量。
- 手机桌面安装：支持添加到主屏幕（PWA manifest）。

## 本地预览

```powershell
cd mobile

python _preview_server.py
```
